# Mintonette

Mintonette is a turn-based 2-player volleyball, text-based, terminal game. Mintonette comes from the original name of the game “Volleyball”, coined in the late 1800s. Mechanically, Mintonette is inspired by the game Battleship, but our twist for the game is that it introduces a system based on the game of Volleyball, adding volleyball elements like zones, serve skills, receive skills, and volleyball conversations.  

Mintonette is a project of ABC for the Principles of Operating Systems Subject.
